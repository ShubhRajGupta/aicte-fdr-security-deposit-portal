# Project naming: Hindi-origin word + full technical name

## Format
`HINDI WORD — Full Technical Expansion`

The name is not a random brand plus a generic tagline. It is a pronounceable Hindi/Sanskrit-origin word in Latin letters; the English technical expansion maps to acronym letters in order and describes the actual approach.

## Procedure
1. Research the target users, technical method and outcome before naming.
2. Extract 3–5 core concepts from the proposed solution.
3. Generate 5–10 candidate Hindi/Sanskrit-origin words, with meaning and pronunciation.
4. Draft an exact English technical expansion, one meaningful term per acronym letter in sequence.
5. Prefer a concise, technically credible expansion over forcing every letter to stand for an unhelpful word. Connecting words only where necessary.
6. Check that the name does not imply a capability not built, nor misleadingly claim AI/security/automation.
7. Search for obvious project/product collisions and record URLs. This quick check is not trademark/legal clearance.
8. Choose and use one name consistently; full expansion on slide 2, short name in figures and captions.

## Sample is format only
`TARANG — Targeted Adaptive Reactive AI-based Network Guard` appears in the old deck. Do not reuse it by default and never reuse that deck's project metrics.

## Output from naming research
`candidate | meaning | acronym expansion | exact letter mapping | relevance | collision check | reason for rejection/selection`.
