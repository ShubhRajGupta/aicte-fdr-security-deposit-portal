# Internal evaluator rubric (diagnostic only; not the official SIH scoring sheet)

Score 0–5 per dimension and state the evidence for each score.

| Dimension | Weak signal | Strong signal |
|---|---|---|
| Approach clarity | PS restatement; vague platform pitch | Concrete input-to-output mechanism and design decisions |
| Ground reality | Generic personas/stock imagery | Actual workflow constraints sourced; field evidence honest and consented |
| Research maturity | Logo wall, random references | Existing methods and systems compared with sourced limits |
| Novelty | “AI-powered” with no comparison | Exact evidence-backed distinction vs relevant alternatives |
| Technical depth | Buzzwords/no data flow | Clear architecture, interfaces, data provenance, edge cases and fallback |
| Feasibility/maturity | Scope exceeds resources; mockup called deployment | MVP boundary, dependencies, gates, real test status and acceptance thresholds |
| Validation | Invented figures | Measured results or an explicit test plan/target with method |
| Impact | Unsupported percentage | Beneficiary, workflow change, baseline/target and limitations |
| References | Links not checked | Primary sources, citations per slide, all claims traceable |
| Visual communication | Empty minimalism or tiny text wall | Dense, partitioned, legible layout with purposeful diagrams and images |
| Template compliance | Rebuilt/rebranded slide master | Exact supplied PPTX and original geometry preserved |
| Defensibility | Team cannot explain choices | Team can defend each component, source, trade-off, failure mode and metric |

Revision gates:
- A low score in evidence, ground reality, feasibility, maturity or defensibility requires technical revision.
- Remove unsupported novelty claims and unmeasured metrics.
- Do not substitute stock photos for field evidence.
- Dense is not synonymous with small type; use partitions, tables and diagrams.
- Every slide must have a source marker and two or more understandable content regions where the template permits.
- Template compliance outranks creative layout.
